# Part IV – Design Evaluation

1. Which Element of Design do you think is most effectively applied in your web application? Why?

I think space is the most effectively applied element in the SPPO-IS web application because the dashboard and login screen use consistent padding, margins, and gaps to create a clean and readable layout. This spacing helps separate sections clearly, reduces visual clutter, and allows users to focus on one area at a time.

2. Which Gestalt Principle contributes the most to your application’s usability? Explain.

The Gestalt principle of similarity contributes the most to the application’s usability because repeated card styles, button shapes, and text treatments make it easy for users to recognize related interface elements. When components look similar, users can quickly understand their function and organization without having to read every label.

3. If you were given another opportunity to redesign your interface, what improvements would you make?

If I had another opportunity to redesign the interface, I would improve the mobile responsiveness and simplify the sidebar navigation by grouping related request paths more clearly. I would also consider adding more visual feedback for active sections and hover states to make the interface feel more interactive.

4. Which part of your interface needs the greatest improvement? Why?

The part of the interface that needs the greatest improvement is the sidebar and navigation flow because it could become overwhelming with multiple request and record links. Improving the sidebar’s organization and reducing cognitive load would help users find the right sections faster.

5. After learning today’s lesson, what new design concepts will you apply to your future software projects?

After learning today’s lesson, I will apply visual hierarchy and consistent spacing more intentionally, and I will use Gestalt principles such as proximity and similarity to organize interface elements. I will also focus on creating clear figure-ground separation so that important content stands out immediately.
