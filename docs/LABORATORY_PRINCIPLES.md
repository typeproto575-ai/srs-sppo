# Principles of Design in SPPO-IS

UI: SPPO-IS Admin Header and Sidebar
Principle: Contrast
Location:
- `<header class="site-master-header">` and `.admin-sidebar`
Explanation:
The dark header and sidebar system navigation contrast strongly with the lighter main workspace, making the system path and account-management area stand out.

UI: SPPO-IS System Hero Banner
Principle: Emphasis
Location:
- `<section class="admin-hero">`
Explanation:
The hero banner is the first thing users notice due to its page title, system subtitle copy, and the system action area defined around the main content.

UI: SPPO-IS Admin Layout
Principle: Balance
Location:
- `<div class="admin-layout">` with `<nav class="admin-sidebar">` and `<main class="admin-content">`
Explanation:
The interface feels balanced by pairing a stable sidebar with a flexible main content area, distributing visual weight evenly across the admin system pages.

UI: SPPO-IS System Cards and Tables
Principle: Pattern
Location:
- repeated `.panel-card`, `.admin-table`, and shared status/badge forms
Explanation:
Repeated card-style elements and table structures create a predictable pattern across the SPPO-IS system, reinforcing a modular and consistent structure.

UI: SPPO-IS System Content Grids and Actions
Principle: Rhythm
Location:
- `.stat-cards`, `.panel-grid`, `.quick-actions`, and `.account-form`
Explanation:
Consistent spacing between grid cards, form fields, and button groups establishes rhythm, so the admin system pages read smoothly from section to section.

UI: SPPO-IS Global Interface
Principle: Unity
Location:
- `.admin-hero`, `.panel-card`, `.admin-table`, `.status-badge`, and `.btn`
Explanation:
The same palette, rounded cards, badge styling, and text treatment are used across the interface, giving the system a cohesive visual identity.
