# Elements of Design in SPPO-IS

Element: Color
Location:
- UI area: system header, admin sidebar, system hero banner, and account status badge colors
Explanation:
Color is used across SPPO-IS to create hierarchy and brand consistency. The dark admin header and green sidebar contrast with lighter content areas, while the active/inactive badge colors and green accents communicate states and actions.

Element: Line
Location:
- UI area: account table rows, form controls, and system content cards
Explanation:
Lines and borders organize data and sections in the admin system interface. Table rows, card outlines, and panel borders separate content clearly and improve readability.

Element: Shape
Location:
- UI area: account cards, buttons, table cells, and sidebar links
Explanation:
Rounded cards, pill status badges, and pill action buttons unify the interface with a soft, modern shape language. Repeated rounded shapes make the system feel cohesive and approachable.

Element: Value
Location:
- UI area: system content panels versus page background
Explanation:
Value contrast is used to separate foreground panels from the background. Lighter content panels on a soft radial page background, plus dark headings and navigation, create visual depth and focus.

Element: Typography
Location:
- UI area: system heading, sidebar labels, table headings, and panel titles
Explanation:
Typography establishes hierarchy through size, weight, and letter spacing. Larger system heading text and bold section headings make important information easy to scan.

Element: Space
Location:
- UI area: admin content layout, account table, and card grids
Explanation:
Consistent padding and gaps create an open, readable system layout. Spacing between cards, sections, navigation items, and table cells keeps the interface organized and reduces clutter.
